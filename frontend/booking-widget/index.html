PartyPilot Booking Widget

Demo — embeddable booking widget dla branży weselnej

Jak to działa

Widget dodaje pływający przycisk w prawym dolnym rogu strony. Po kliknięciu otwiera się modal z 3-etapowym formularzem rezerwacji:

  • Krok 1: Wybór daty z kalendarza
  • Krok 2: Wypełnienie danych kontaktowych
  • Krok 3: Potwierdzenie i wysłanie rezerwacji

Kliknij przycisk 📅 w prawym dolnym rogu, aby przetestować.

Embed na swojej stronie

Dodaj ten kod przed zamknięciem </body>:

<script src="https://widget.partypilot.pl/widget.js"
        data-tenant-id="TWOJ_TENANT_ID"
        async></script>

Opcje konfiguracji

data-tenant-id ID Twojego tenanta wymagane data-api-base URL backendu API https://api.partypilot.pl/api data-position Pozycja przycisku bottom-right

Demo

Ta strona ładuje widget z identyfikatorem T-demo. Ponieważ to demo, dane z API nie zostaną załadowane — widget pokaże komunikat o błędzie, co pozwala przetestować obsługę sytuacji awaryjnych.

Pliki źródłowe

📄 widget.js 🎨 widget.css

Widget jest w pełni samodzielny — nie wymaga zewnętrznych bibliotek ani frameworków. Działa na każdej stronie (WordPress, Wix, Shopify, własny HTML).
