💬 Chat Widget — Demo

Widget czatu AI dla platformy PartyPilot

ℹ️ Widget jest już załadowany. Kliknij bąbelek czatu w prawym dolnym rogu, aby go otworzyć.

Jak to działa

Ten widget to samodzielny, embeddowalny komponent JavaScript. Ładuje się na stronie jako pływający bąbelek czatu. Po kliknięciu otwiera panel z AI asystentem, który odpowiada na pytania o usługi, pakiety i ceny organizatora wesel.

Widget nie wymaga żadnych zależności ani frameworków. Działa na każdej stronie HTML — wystarczy dodać jeden tag <script>.

Testowe ID tenanta

Ten demo używa data-tenant-id="T-demo". API zwróci symulowane odpowiedzi dedykowane dla branży weselnej.

Aby przetestować z własnym tenantem, zmień atrybut data-tenant-id w tagu script na swój identyfikator.

Kod do osadzenia

Skopiuj ten kod na swoją stronę:

<script src="https://widget.partypilot.pl/chat.js"
        data-tenant-id="TWOJ_TENANT_ID"
        async></script>

Opcje konfiguracji

Atrybut Opis Domyślnie
data-tenant-id ID tenanta (wymagane) —
data-api-base URL API https://api.partypilot.pl/api
data-position Pozycja bąbelka bottom-right

API JavaScript

Widget udostępnia globalny obiekt window.PartyPilotChat:

// Otwórz panel czatu
PartyPilotChat.open();

// Zamknij panel czatu
PartyPilotChat.close();

// Przełącz panel
PartyPilotChat.toggle();

// Wyślij wiadomość programowo
PartyPilotChat.send("Jakie macie pakiety?");
